# Editor mockup references

Read the accepted [editor layout](../../doc_v1/interface/workspace-and-canvas.md#editor-layout) before using these images.
It defines the horizontal project tabs, Dashboard, vertical toolbar, and contextual save feedback for V1.
Each top tab represents a separate `.orc` project.

Use these mockups only as inspiration for the workspace's rough structure.
Do not reproduce their exact pixels, dimensions, typography, colors, or sample content.
Use `doc_v1` for layout and behavior, [desgin_system/](../desgin_system/DESIGN.md) for visual foundations, and [desgin_blog/](../desgin_blog/README.md) for design reasoning.
Adapt these references into a coherent ORC-web interface.
